# Lisensi aset

Seluruh audio (drone, pad, hujan, angin, serangga, langkah, impact, swell, nada metalik, dropout hening) dibuat sendiri secara prosedural oleh `scripts/prepare-audio.py` (numpy/scipy/ffmpeg). Tidak ada sampel, musik, atau aset berlisensi pihak ketiga.
Narasi = VO1 & VO2 buatan pengguna.
Semua visual dibuat prosedural (SVG/CSS) di Remotion; tidak ada gambar/footage pihak ketiga.
