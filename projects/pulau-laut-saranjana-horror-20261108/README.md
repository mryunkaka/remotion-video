# Saranjana — Jejak Kerajaan Pulau Halimun

A two-minute vertical motion-graphic horror retelling based on documented Kotabaru folklore. Its visual language follows the supplied reference: dark cartographic panels, warm gold typography, paper/map motifs, layered silhouettes, and kinetic editorial transitions. It is deliberately illustrated rather than uniformly photorealistic.

The on-screen Indonesian text is the story track. No matching voice recording was supplied and the previous episode's voiceover was not reused. Audio is original instrumental ambience and synchronized effects; the video must not be described as having a spoken narration.

Render: from the repository root, run the Remotion CLI against `projects/pulau-laut-saranjana-horror-20261108/src/index.ts`, composition `PulauLautHalimun`.
