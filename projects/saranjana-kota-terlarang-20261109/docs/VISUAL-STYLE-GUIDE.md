# Visual style guide

- Medium: ilustrasi sinematik SVG/2.5D bergaya folklorik, bukan fotorealistik. Tidak ada klaim bahwa gambar sintetis adalah footage nyata.
- Palet: biru laut tinta `#07141C`, teal gelap `#123039`, kabut abu-abu `#82908B`, cahaya karang emas `#D6A66A`, teks gading `#E8E4D8`.
- Dunia: garis horizon dalam, foreground gelap, midground kabut, silhouette karang/perahu/pulau, skyline organik; kedalaman dibuat dengan skala/parallax terukur.
- Figur: Datumabrur hanya siluet dewasa sederhana dan konsisten; ikan todak berupa bayangan besar, tanpa anatomi detail/serangan grafis.
- Gerak: semua frame-driven; aerial drift, tracking lateral, locked silence, swell dan parallax berbeda per shot. Kabut/riak hanya sebagai environment relevan.
- Teks: off-white, kontras dan margin vertikal aman; maksimal dua baris. “@terangbulan.media” hanya branding tambahan di penutup.
- Batas faktual: Saranjana prompt bertentangan dengan audio. Cerita visual mengikuti ASR Pulau Halimun. Lokasi/kejadian ditandai legenda; jangan tunjukkan peta faktual atau klaim visual photoreal.
- Subtitle: transcription/narration.srt dari ASR; confidence segmen layak ditinjau, timing kata perkiraan Whisper.
