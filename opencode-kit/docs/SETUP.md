# Legacy OpenCode kit

This kit is retained as a historical/reference snapshot. Do not copy its `opencode.json`, `AGENTS.md`, template, or commands into the repository root: the active setup is already installed at the root and has updated isolated-project rules.

Use [the active installation guide](../../docs/INSTALLATION.md), [video workflow](../../docs/OPENCODE-VIDEO-WORKFLOW.md), and root `/make-video` command instead. The kit's BGM examples assume a particular underwater story and should not be reused as universal visual or sound direction.
